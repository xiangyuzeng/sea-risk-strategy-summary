## 附录二、就本记录可提的流程观察

以下均为本条记录自身可见的问题，不涉及被脱敏的内容：

1. **必填字段留白。** 「是否达到命中样本参考门槛」「发布前评估结论」「leader审批结论」
   「leader审批人」「上线后监控责任人」均标注为必填但为空，而「当前状态」已填「确认」——
   审批链路留痕不完整。

2. **风险画像六项全部空白。** 代下行为是否明显、IP/设备是否聚集、手机号是否命中猫池/高风险标签、
   API链路是否异常、设备指纹是否高风险、礼品卡转赠是否异常 —— 六项均未填写。
   本例的黑产判定质量由「黑产评估依据说明」这段自由文本撑起，而非由这六个结构化字段。

3. **误伤已识别但无人处置。** 「是否识别潜在误伤人群」填「是」并写出了两类场景，
   但「发布前评估结论」与「leader审批结论」均空白 —— 无从判断这两类误伤被谁、依据什么判定为可接受。

4. **近 7 日同期基线未填。** 两项均留空，无法判断本次观察窗的量级相对历史是否正常。

5. **硬特征规则的固有脆弱性。** 两条规则均以具体字段取值的等值判断为主（其中一条含一个二选一子条件）。
   命中条件高度具体，对抗方只要调整所依赖的特征即可使其失效 —— 适合应急期快速止血，
   不适合长期主力。原件未记录这一权衡，也未设定有效期或复评时间点。
