## 就本批记录可提的流程观察

1. **两项必填字段无法给出单值。** 「准确率」所依赖的「风险样本量」在 SOP 中没有定义，
   也没有给出计算公式；两种合理读法在 99.9% 门槛下结论相反。
   「是否达到最低整体调用量/用户量」取决于本场景按哪一档策略判定，该归属亦未确认。
   两处均以**两种口径并列**呈现，未替人做判断。
2. **审批链路留痕不完整。** leader 审批三项、发布前评估结论、上线后监控责任人、复核人
   均标注必填但为空 —— 与本仓根目录记录的情况一致。
3. **风险画像六项多为「不适用」或「暂无法判断」。** 本场景无代下单、无礼品卡链路，
   设备指纹字段全为空，猫池号标签无数据源 —— 黑产判定实际由「黑产评估依据说明」
   一段自由文本承担，而非由六个结构化字段承担。
4. **黑名单类策略的名单成员不是数据结论。** S6/S7/S9 依赖运营维护的黑名单，
   名单本身需人工逐个确认非公共出口段，这一步在记录中尚无留痕字段。
